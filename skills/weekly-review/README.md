# weekly-review

Personal-mode skill that produces a Sunday-evening weekly review.

## Inputs
- Last 7 days of `journal_entries`
- Past week of `briefings` (morning + evening)
- Completed vs missed Google Tasks
- Current `goals` rows

## Output
Markdown saved to `briefings` with `kind=weekly`. Suggested sections:
*What happened*, *Wins*, *Friction*, *Goal status*, *Adjustments for next week*.
